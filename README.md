# Sboard Project (게시판 프로젝트)
> Spring Boot 기반의 게시판 프로젝트입니다. 기본적인 CRUD 기능과 파일 업로드, 페이징, 검색 기능을 제공합니다.

### Backend & Frontend 기술 스택

| Backend 기술 | 버전 | Frontend 기술 | 버전 |
|-------------|------|--------------|------|
| **Java** | 17 | **Thymeleaf** | 3.1.0 |
| **Spring Boot** | 3.4.1 | **Bootstrap** | 5 |
| **Spring Security** | latest | **jQuery** | latest |
| **Spring Data JPA** | latest |  |  |
| **QueryDSL** | latest |  |  |
| **ModelMapper** | latest |  |  |
